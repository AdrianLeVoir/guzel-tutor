# Сайт репетитора по истории — Гузель

Одностраничный лендинг для репетитора по истории (ЕГЭ / ОГЭ).

## Как задеплоить на GitHub Pages

1. Создай новый репозиторий на GitHub (например `guzel-tutor` или `history-tutor`).
2. Загрузи все файлы из этой папки в корень репозитория:
   - `index.html`
   - `hero-painting.jpg`
   - `about-photo.jpg`
3. В настройках репозитория → **Pages** → Source: **Deploy from a branch** → Branch: `main` / `root` → Save.
4. Через 1–2 минуты сайт будет доступен по адресу:
   `https://ВАШ_ЮЗЕРНЕЙМ.github.io/НАЗВАНИЕ_РЕПО/`

## Что нужно доработать после деплоя

- Заменить ссылки на Telegram / VK / WhatsApp на реальные
- Добавить реальную фотографию (если нужно)
- По желанию — кастомный домен

## Локальный просмотр

Просто открой `index.html` в браузере.
